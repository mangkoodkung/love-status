📊 ระดับสถานะ (Status Levels)

กำหนดว่าแต่ละ % หมายถึงอะไร + prompt ที่จะ inject ให้ LLM

⚙️ ตั้งค่าตัวละคร
(%)

📤 ส่งออก: สร้างไฟล์ JSON สำหรับแจกจ่าย (รูปจะถูกเข้ารหัส)
📥 นำเข้า: โหลดไฟล์ JSON จาก Creator เพื่อใช้กับตัวละครปัจจุบัน

วิธีใช้:
• สร้างแพ็คพร้อมรางวัลที่กำหนดเอง
• ใส่ URL รูปภาพสำหรับรางวัล
• ส่งออก/นำเข้าแพ็คเป็นไฟล์ JSON
• เกณฑ์เป็น % ของคะแนนสูงสุด
• ตั้งค่าระดับสถานะ + prompt ตาม level
• ส่งออก Card Data เพื่อแจกจ่ายให้ user อื่น

📐 ขนาดรูปแนะนำ:
• ขนาด: 400×400px หรือ 400×600px
• Format: JPEG หรือ WebP
• ไฟล์ไม่เกิน 500KB
• อัตราส่วน: 1:1 หรือ 2:3
